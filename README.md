## 理念与方法论

### [这不是答案](https://timyefi.github.io/posts/this-is-not-the-answer.html)

*2026-09-10*

Skill 不是答案，AGI 也不是答案。答案在使用过程中产生——每个人的机器、每个人的数据都需要被单独训练，通用模型解决不了智能在个人这一侧落地的问题。
